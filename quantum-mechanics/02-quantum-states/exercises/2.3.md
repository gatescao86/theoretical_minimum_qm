## Problem
**(a)**
Since 
$$|i \rangle = \alpha|u\rangle + \beta|d\rangle$$
$$\langle u|i \rangle = \alpha\langle u|u\rangle + \beta\langle u|d\rangle = \alpha$$
$$\langle i|u \rangle = \alpha^*$$
Therefore, $$\alpha^*\alpha = \frac{1}{2}$$
Similarly, $$\beta^*\beta = \gamma^*\gamma = \delta^*\delta = \frac{1}{2}$$

**(b)**
$$\langle r|i \rangle = (\frac{1}{\sqrt{2}}\langle u| + \frac{1}{\sqrt{2}}\langle d|)(\alpha|u \rangle + \beta|d \rangle) = \frac{\alpha + \beta}{\sqrt{2}}$$
Then, $$\langle i|r \rangle = \frac{\alpha^* + \beta^*}{\sqrt{2}}$$
$$\langle i|r \rangle\langle r|i \rangle = \frac{1}{2}(\alpha^*\alpha + \alpha^*\beta + \alpha\beta^* + \beta^*\beta) = \frac{1}{2}$$
Since $$\alpha^*\alpha = \beta^*\beta = \frac{1}{2}$$
$$\alpha^*\beta + \alpha\beta^* = 0$$
Similarly, $$\gamma^*\delta + \gamma\delta^* = 0$$

**(c)**
Define $$z = \alpha^*\beta$$
$$z^* = (\alpha^*\beta)^* = \alpha\beta^*$$
From part (b), $$z + z^* = 0$$
For any complex number $$z = a + ib$$
$$z^* = a - ib$$
$$z + z^* = (a+ib) + (a-ib) = 0$$
$$2a = 0$$
The real part of $z$ is zero. Therefore, $\alpha^*\beta$ must be purely imaginary.
